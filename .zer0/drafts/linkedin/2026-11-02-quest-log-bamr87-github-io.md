My portfolio's stats strip has one number typed by hand: the years I've been building. It is also the only one no machine checks.

That is bamr87.github.io, a side quest in my Quest Log. One list of projects goes in. Every night a robot asks GitHub for the stars, languages and links, and rebuilds the dashboard. If a single request fails, it writes nothing. About a third of the site's commits are that robot.

An audit in October found every page carrying the site name "Prod". The author field said null 27 times, and elsewhere ChatGPT, GitHub Copilot and Apple. An agent gave all 57 bylines back to one author in a single diff. No calibration meeting required.

Day 3 of my daily deep dive pointed the AI reviewer at the site. It filed three findings, each a decision only I can make, one of them a setting no agent may touch. Its score isn't recorded yet, so I'm not printing one. Inventing the number is the self-review's job.

The screenshots, the findings and what is still open are in the article.

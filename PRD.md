# PRD — bamr87.github.io

> Product requirements for the bamr87.github.io profile and portfolio site — problem, users, goals, features and proposed success metrics — derived from the repo's README, agent docs, config and code, with anything they do not state marked **TBD**.

## 1. Overview / problem

Amr Abdel-Motaleb's personal profile, résumé and project portfolio site, built with Jekyll on GitHub Pages (https://bamr87.github.io/). The README itself is the profile/résumé page.

## 2. Target users

- Recruiters, clients and collaborators evaluating Amr's experience
- Visitors browsing the project portfolio

## 3. Goals and non-goals

**Goals**

- Present profile, résumé and featured projects
- Link to the full portfolio and contact channels
- Build and deploy on GitHub Pages

**Non-goals**

- Hosting project source (lives in each project repo)

## 4. Core features (current)

- Profile & résumé page (README with front matter, permalink `/profile/`)
- Featured projects table and portfolio pages under `pages/`
- Dockerfile for local preview
- Scripts/tools for site maintenance

{%- comment -%} posts-timeline.html — every post on the site as a timeline, with three views. Used by the /posts/ page (pages/_posts/2000-01-01-index.md). Without JavaScript it is a complete timeline: years, months and posts, newest first. The script adds the controls: Timeline / Cards / List views, a category filter, a title or tag search, newest/oldest order, and a posts-per-month strip that jumps to a month. One list of posts is restyled by the view; it is never rebuilt, so links, images and headings stay where the build put them. Lists every post the theme's news layout lists (all but index pages), so the count matches what a visitor can reach. Colors come from Bootstrap's CSS variables, so the theme's light and dark skins both apply.
